# 如月怜的游戏连结：Steam DLC

独立 AstrBot alpha 插件，为游戏连结提供 Steam 共享账号与 Dota2、CS2、Deadlock 四个模块。

当前正在实施，尚未形成可安装 alpha。Dota2 目标为匿名 OpenDota 最近战绩、单场摘要和玩家资料；CS2/Deadlock 首期提供接入、启停、帮助与准确状态。

工程入口：[执行与验收](docs/plan.md)、[架构合同](docs/architecture.md)、[协作约定](docs/collaboration.md)。安装产物、兼容版本、命令示例和实际验证结果将在候选验收后补齐。

Steam 关联属于用户主动声明（self_asserted），不代表已验证账号所有权。日常机器人、正式合并及 Release 不在本轮操作范围。
