# 协作约定

采用 economy。root 维护需求、基线、合同、状态和写入权；角色不要求常驻 agent。仅为依赖已就绪且可独立验收的切片委派，同时最多两个子任务。子 agent 不再委派。

先发现本机运行时/配置和可见模型目录，按风险选最小胜任模型；模型、effort、speed 分记，无法核实的生效值记 unknown。默认不增加收费加速。机械任务可轻量，身份、CAS、注册、卸载、生命周期及独立审查需要足够推理能力。配置不修改，账户信息和调度快照留本地。

本轮任务书指定修复再审最多两轮（失败尝试计入）；仍有 Blocker/Important 时停止机械返修，做有边界的根因会诊并报告新计划/预算需求。没有额外总时间、金额或总尝试硬限额；不编造限制。进展门槛是建库、规范提交、合同冻结、最小闭环、集成冻结、独审及交付。费用/token 无实测时记 unknown，订阅消耗不从 API 单价估算。累计初始委派输入软目标 24k tokens，后续必要上下文单独记录；这是节省上下文的估计，不是用户硬限额。

每张本地任务卡记录 REQ、修订、输入来源、就绪依赖、唯一写入范围、只读范围、请求与可见生效模型/effort/speed、预算、验收、证据及退出条件。交接传必要事实和路径；不默认复制全历史或整仓。补证/返修优先原 agent。公共合同由 root 串行落地。

高风险候选冻结后，由未参与设计/实现的新上下文独审；先读取需求及代码形成判断，再对照作者说明。审查带 Blocker/Important/Polish、位置、影响和证据，修改后重验受影响项。未经闭合的 Blocker/Important 不能交付为通过。

dots 独占主项目页面工作。本轮只消费明确提交上的稳定页面合同，不改布局、主题、锁文件、生成物或其工作区；必要后端公共接口差异交对应 owner。未来整合后统一重建资源，禁止手工拼接生成物。
