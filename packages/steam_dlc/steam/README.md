# Steam 游戏生涯拼图

`wall` 使用当前用户的关联；`wall_explicit` 和页面必须明确提供账号。命令先返回持久任务回执；页面可提交、查看状态、逐页下载、取消和重试。关闭页面只停止轮询，刷新后恢复任务ID。关联属于用户声明，不是 Steam 所有权验证。页面保持真实 `WEB_PUBLIC` 来源，不创建聊天身份或自动发送多条消息。

默认 `dense / standard / 2:3 / normal / cover`，最多纳入500项，包含软件及未知类型，排除零时长和未知时长。明确保存的 `poster_include_apps=false` 继续只看已确认游戏。`--mode legacy` 保留旧 WeightedCollage，最多200项。

`--source games` 是 XML 最多5项公开样本，`recent` 是主页最多3项最近展示样本。`full` 经 Core 注入部署者配置的可选 Steam Web API Key，请求真实库；模块不读取明文 Key。未配置、无效、私密或上游失败分别反馈，不用样本替代。`complete_library` 仅描述 API 来源覆盖；筛选与入图完整性另有 `all_eligible_included` 和 requested/eligible/included/omitted 计数。

支持 `--preset single|standard|long`、`--aspect 2:3|9:16|1:2`、`--quality normal|hd`、`--fit cover|contain`、`--limit N|all`、`--all-apps`、`--games-only`、`--refresh`。数量最小20，快捷20/50/100/200/500/1000/不限；1001、1500、2500均可手填。命令与页面完整校验有限十进制后向零截断，例如1500.9→1500；布尔、空串、混合文字、非有限值和超出JSON安全整数范围会明确拒绝。结构化工具使用integer `limit`和`limit_mode:top|all`，有限1000不会变成不限。不限覆盖来源实际返回范围，不把公开样本说成完整库。2:3为原版竖海报；窄版 cover 等比裁剪，contain 保留全图并填背景。

锚点间线性插值面积，再对平方根按 half-up 量化为整数倍率。每张占 `k×k` 格；大小不依赖库内最大时长。正常基元为54×81/96/108，20列内容宽1080；高清整体放大4/3为72×108/128/144，内容宽1440。Core 大块优先、稳定补空；物理阅读顺序可跨逻辑排名区间，同分逻辑列表按数值 AppID。过长标题明确显示省略号，AppID保持完整。

以100项一批核查候选元数据，筛选后只为已选作品取图；每批最多128个作品，并按倍率与4页内容预算自适应缩小，再交给Core测量页头页脚与排版，素材HTTP并发4。后续批继续发布结果，没有1000项或总8页截断。普通刷新游戏库不会强制重下有效封面；普通/高清、预设及比例共享同一官方竖封面原始变体。原图使用稳定来源身份和Core `RAW`类，派生图使用Core `DERIVED`类；活跃批次pin原图后渲染并在finally解除pin。原图保留策略和有界配额由Core通用资源服务执行。个人成图为任务owner的`USER/OUTPUT`资源，结果ID不授予读取权限。完整库快照保留300秒，并按可信凭据修订隔离；清除或轮换Key不复用旧快照。

命令回执可用`/ygl steam wall status <任务ID>`查询；`result <任务ID> --page N --image N`沿Core不透明游标定位本地20项结果页，每次只输出选中一张图。`cancel`和`retry`先读取当前修订再CAS执行，冲突需重新查询，不自动重发。COMMAND/Tool使用当前可信用户命名空间，Dashboard使用独立命名空间；不能在另一个身份或页面凭任务ID读取结果。

每次渲染仍有像素、输入字节和PNG预算，由Core测量页头/页脚后执行；持久任务把有界批次继续到选集结束，结果每次本地分页20项。失败保留已完成页和进度，显式重试从头重算，不宣称自动checkpoint续跑。重启中的running任务标记中断，可显式重试。来源返回、符合、选择、生成、待处理、缺图和来源完整性分别报告。预算失败不会作为全量完成返回。

Core可信索引绑定源内容hash、资源修订及文件版本，Windows额外使用ChangeTime；文件变化或证据未知时完整复核。成图命中仍完整读取并校验PNG，不逐张全读/解码封面。共享衍生只由经过验证的公共原图产生；账号、时长、选集、文案及成图不会进入公共缓存。

`/ygl steam wishlist [账号] [--page N]`匿名读取Valve第一方`IWishlistService/GetWishlist/v1`。工具和页面必须明确账号，命令可使用可信本人关联。默认最近添加排序，同时间按数值AppID；每页20项，仅补全当前页的名称、地区价格和发售状态，StoreBrowse按完整查询JSON不超过512字符动态分批。免费、未发售、无本地价格、商店/地区不可用、补全失败保持区别。明确`items:[]`才代表空单，缺失列表、私有、429和来源故障不会折成0项。无需Key、Cookie、Steam登录；这个第一方端点仍未保证长期稳定。
